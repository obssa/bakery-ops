# Demo product photos

Stock photos for the demo catalogue only, one per demo product. The admin replaces them with photos of the real products from
the product page. `manifest.json` lists each file, the product name it matches and its source page.

Every photo is free to use under its site's licence (the Unsplash License or the Pexels License: free for commercial use, no
attribution required, not to be sold as is or compiled into a competing photo service). They were cropped to 4:3, resized to
1600 x 1200 and saved as WebP without metadata. No person's face is in any photo, and no brand or label is visible.
